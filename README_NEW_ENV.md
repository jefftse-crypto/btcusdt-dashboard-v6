本專案已由 Manus AI 進行了深度整合與重構，將原本分散的 11 個分類整合為 5 個核心區塊，並將 SMC、PA、纏論等同類面板融合成統一的進階分析面板。

## 🚀 快速啟動步驟

### 1. 環境準備
確保你的電腦已安裝以下工具：
- **Node.js** (建議 v18 或更高版本)
- **pnpm** (建議使用 `npm install -g pnpm` 安裝)

### 2. 安裝依賴
在專案根目錄執行：
```bash
pnpm install
```

### 3. 設定環境變數
專案中已包含 `.env` 檔案。如果你需要更換 API Key 或資料庫，請編輯 `.env`：
- `BINANCE_API_KEY` / `BINANCE_API_SECRET`: 用於獲取即時數據。
- `DATABASE_URL`: 資料庫連線字串（預設為 SQLite/MySQL 相容）。

### 4. 啟動服務
本專案為前後端分離架構，你可以分別啟動或同時啟動：

**同時啟動（推薦）：**
```bash
pnpm dev
```

**分開啟動：**
- **後端 (API + WebSocket):** `pnpm dev:server` (預設埠號: 3000)
- **前端 (Vite + React):** `pnpm dev:client` (預設埠號: 5173)
