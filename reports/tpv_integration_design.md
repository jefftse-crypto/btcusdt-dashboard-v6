# TPV 改良层接入设计

现有 `server/backtest_htr_v3_multisymbol.ts` 已具备 4H 定方向、1H 状态确认、15m 触发、CVD、多币种择优、每日最多一单与分批止盈。TPV 不适合推翻这些逻辑，而适合作为 **V3 之后的结构质量过滤层**。

| V3 位置 | 原逻辑 | TPV 改良方式 |
|---|---|---|
| 4H `trend4Up/trend4Dn` | 用 EMA50/EMA200 与 ATR 判断方向 | 保留，符合 TPV「小周期服从大周期」。 |
| 1H `state1Up/state1Dn` | 用 EMA20/EMA50 与 ATR 确认状态 | 强化为 1H 斜率与 15m 斜率同向，模拟截图中的 EMA55/均线斜率评分。 |
| 15m 回踩/反抽触发 | 触碰 EMA20/VWAP 后收回 | 增加「第三触点」代理：最近 72 根 15m 内至少 3 次触碰 EMA50/VWAP 动态支撑/压力，且间隔足够。 |
| 突破与前日高低 | 作为加分项 | 不作为 TPV 核心，避免追价；TPV 版更偏向关键位附近入场。 |
| CVD 与量能实体 | 已有顺势 CVD 与成交量实体 | 增加收线验证：多头收在 K 线 55% 以上且收盘高于开盘，空头收在 45% 以下且收盘低于开盘。 |
| RR 与风控 | `minRr` 1.8–2.1 | TPV 版提高至 2.4–2.8，接近截图中 2.72、3.35、4.55 的盈亏比。 |

初版 V4/TPV 回测将新增以下配置：`v4_tpv_pool8_quality`、`v4_tpv_pool8_strict`、`v4_tpv_core4_quality`。目标不是提高交易数，而是测试胜率是否能从 V3 最佳的约 64.94% 向 68–70% 靠近，同时观察 PF 与收益是否没有明显恶化。
