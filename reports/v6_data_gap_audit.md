## Binance 官方可补充数据目录

| 数据类别 | 官方公开目录 | V6 用途 | 建议优先级 |
|---|---|---|---:|
| fundingRate | `data/futures/um/monthly/fundingRate/` | 永续合约持仓期间资金费率扣减/增加 | P0 |
| markPriceKlines | `data/futures/um/monthly/markPriceKlines/` | 更接近强平与触发价格的风险模拟 | P1 |
| premiumIndexKlines | `data/futures/um/monthly/premiumIndexKlines/` | 溢价、基差与资金费率环境过滤 | P1 |
| bookTicker | `data/futures/um/monthly/bookTicker/` | 点差与滑点模型校准 | P1 |
| aggTrades/trades | `data/futures/um/monthly/aggTrades/`、`trades/` | 成交量微结构与冲击成本估计 | P2 |

## V6 必须修正的实盘可信度缺口

| 缺口 | 旧版状态 | V6 处理方式 |
|---|---|---|
| 手续费 | 旧版主要比较净值未显式扣除双边 maker/taker 成本 | 增加可配置 `fee_bps_per_side`，默认按保守 taker 成本计算 |
| 滑点 | 旧版以理想价格成交 | 增加 `slippage_bps_per_side` 与压力倍数 |
| 资金费率 | 旧版本地未纳入资金费率 | 先实现可下载/可缺省的 funding 模块；无 funding 文件时用 0 或压力参数 |
| 样本外验证 | V5 已有探索，但选择偏差仍高 | V6 固定参数后做滚动窗口与最后 3 个月纯样本外 |
| 订单成交假设 | 旧版未区分信号价、下一根开盘、止盈止损穿越顺序 | V6 记录保守触发规则与冲突处理 |
| 纸交易 | 尚无统一日志 | 输出纸交易验收清单与日志模板 |
